# Powerspike

Free desktop companion app for League of Legends (Windows), used privately by a small group of friends.

- Champion pick suggestions for the player's role, based on the draft and the player's champion pool
- Rune page and item set suggestions adapted to the enemy team (one rune page, one item set)
- Lane matchup tips, first-clear and objective-timing advice
- Post-game summary of the player's own stats

Download: see [Releases](../../releases/latest). The app updates itself from signed releases in this repository.
